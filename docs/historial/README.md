# Historial de desarrollo

Esta carpeta conserva entregables terminados de agentes y copias parciales de rondas anteriores. No forman parte de la documentación operativa de OpenFrame.

- `rondas/`: tareas, informes, mapas y briefs del desarrollo del visor real.
- `ref-S/`: copia parcial y obsoleta de un intento anterior, conservada solo para trazabilidad.

La documentación de `ref/maqueta/docs/` permanece junto a la maqueta porque describe la referencia de fidelidad que todavía usan las herramientas de comparación.
